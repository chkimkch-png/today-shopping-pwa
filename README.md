# 오늘의 장보기 PWA

안드로이드 스마트폰의 크롬에서 설치해 사용할 수 있는 장보기 앱입니다.

## 포함 기능
- 이마트, 탑마트, 롯데맥스, 제일종합, 5일장 + 직접 이름을 정하는 1개 마트
- 상품명 또는 사진으로 상품 등록
- 사진 촬영 또는 갤러리에서 이미지 선택
- 단가·수량 입력 및 상품별 금액 자동 계산
- 구매 완료 체크 시 완료 목록 하단으로 이동하고 흐리게 표시
- 미구매/구매 완료 각각 상품명 가나다순 정렬
- 마트별 합계, 구매 완료 금액, 미구매 금액, 당일 전체 합계
- 날짜별 목록 저장 및 과거 내역 조회
- (v4) 달력에서 장 본 날 보라색 표시, 상단 메뉴 완전 고정(스크롤은 아래 영역만)
- (v3) 상단 고정(제목·우측 상단 날짜·장보기 선택/새 장보기/장보기 종료·구매 완료·당일전체 합계·메모), 상품 입력 영역 재배열, 날짜별 메모 저장
- (v2) 상단 고정 영역(제목·날짜·구매/미구매·마트 선택·당일 합계), 촘촘해진 간격
- (v2) 과거 입력 상품명 자동 저장, 가나다순 + 초성(ㅇㅇ→우유) 검색, 선택 시 최근 단가·사진 자동 입력
- (v2) 사진 자르기(crop), 사진 찍기/앨범 선택, 기본 상품 그림, 내 사진 보관함
- IndexedDB 로컬 저장, 서비스 워커 캐시를 통한 기본 오프라인 실행

## 설치 방법 (Android)
1. 이 폴더의 파일 전체를 HTTPS를 지원하는 웹 호스팅에 올립니다. 예: GitHub Pages 또는 Netlify.
2. 배포된 주소를 안드로이드 스마트폰의 Chrome으로 엽니다.
3. Chrome 메뉴(⋮)에서 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
4. 홈 화면에 생성된 `장보기` 아이콘으로 실행합니다.

## 중요한 사항
- PWA 설치에는 HTTPS 주소가 필요합니다. 파일을 휴대전화에 복사해 `index.html`을 직접 여는 것만으로는 설치 가능한 PWA가 되지 않습니다.
- 최초 접속 후 앱 파일이 캐시되면 기본 화면은 오프라인에서도 열 수 있습니다.
- 상품/날짜 데이터와 사진은 해당 브라우저의 IndexedDB에 저장됩니다. 서버로 전송하지 않습니다.
- 브라우저 데이터 삭제, 앱 제거, 기기 변경 시 데이터가 사라질 수 있으므로 중요한 내역은 별도 기록을 권장합니다.
- 여섯 번째 마트 이름은 마트 선택 화면 아래의 `여섯 번째 마트 이름 변경`을 눌러 변경합니다. 변경 이름은 해당 날짜의 장보기 데이터에 저장됩니다.
- 이 패키지는 배포용 소스 파일입니다. 아직 특정 웹 주소에 배포하거나 실제 스마트폰에서 설치 테스트한 상태는 아닙니다.

## 개발 파일
- `index.html`: 화면 구조
- `presets.js`: 기본 상품 그림 목록(이모지, 실제 사진 경로 추가 가능)
- `styles.css`: 화면 디자인
- `app.js`: 목록·정렬·계산·로컬 저장 기능
- `manifest.webmanifest`: PWA 설치 정보
- `service-worker.js`: 오프라인 캐시
- `icons/`: 앱 아이콘

## 업데이트 방법 (v2)
- 같은 주소에 파일 전체를 덮어써서 올리면 기존 저장 데이터(날짜별 목록)는 그대로 유지됩니다.
- 반영이 안 보이면 앱을 완전히 종료했다가 다시 실행하세요(서비스 워커가 새 버전을 받는 데 한 번 더 열어야 할 수 있습니다).
